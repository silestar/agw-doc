# 统计与日志

## 日志系统

AGW 使用 zap 高性能日志库，支持**按日归档**：

```
logs/
  agw-2026-05-20.log
  agw-2026-05-21.log
  agw-2026-05-22.log
```

### 系统日志

- 级别：debug / info / warn / error
- 格式：JSON（可配控制台格式）
- 输出：stdout + 文件

### 请求日志

每次请求结束后，AGW 写入一条完整记录，包含：

| 字段 | 说明 |
|------|------|
| 请求时间、耗时 | 精确到毫秒 |
| 消费者 Key（脱敏） | 标识调用方 |
| 请求模型、渠道、账号 ID | 完整路由信息 |
| Token 用量（prompt/completion） | 计费基础 |
| 状态码、错误信息 | 成功/失败原因 |
| `retry_chain`（JSON） | 完整重试链路 |

### 每日统计日志

可选开启，自动生成每日统计摘要：

```
2026-05-20 统计：
  总请求：12,345
  成功率：98.7%
  总 Token：45,678,901
  按模型分布：
    gpt-4: 5,678 → 渠道A 60%, 渠道B 40%
    claude-3: 3,210 → 渠道C 100%
```

## Redis 实时统计

高性能实时计数，用于：
- 消费者 RPM/TPM 配额检查
- 渠道/账号实时调用量
- 故障计数

Redis 不可用时自动降级为 SQL 查询（性能降低但系统仍可用）。

## 可视化统计面板

管理面板提供多维度可视化：

- **概览仪表盘**：今日请求数、成功率、Token 用量、活跃密钥数
- **渠道分析**：按渠道/适配器的调用分布、延迟分布
- **账号分析**：每个账号的健康状态、使用频率、故障历史
- **消费者分析**：Top 消费方、配额使用率、异常调用
- **趋势图**：7 天/30 天调用量变化
