# 消费者管理

## 核心概念

**消费者**是 AGW 中最小的权限单元——每个使用 AGW 的用户或应用都对应一个消费者。

## 数据模型

```
consumers                           密钥身份
  ├── api_key_hash                  API Key（SHA-256 哈希存储）
  ├── name                          显示名称（便于管理）
  ├── status                        启用/禁用
  └── key_groups                    绑定到消费者分组
```

## 消费者分组

消费者分组用于**批量权限控制**：

- 一个分组可包含多个消费者
- 每个消费者在分组内有独立配额：
  - `quota_rpm`：每分钟最大请求数
  - `quota_tpm`：每分钟最大 Token 数
- 分组绑定到渠道分组，控制可访问的模型

## 配额计算

```
实时计数：Redis INCR + TTL（高性能）
持久化：定时从 Redis 同步到 SQL 数据库
降级：Redis 不可用时回退到数据库计数（精度降低但可用）
```

## API Key 管理

| 操作 | 说明 |
|------|------|
| 生成 Key | 随机生成 `sk-` 前缀密钥，SHA-256 哈希后存储 |
| 吊销 Key | 设置状态为 disabled，保留统计记录 |
| 查看 Key | 管理面板只展示脱敏形式（`sk-abc****`） |
| 统计 | 按 Key 维度查看调用量、成功率、延迟 |
