# 插件开发概览

## 什么是 AGW 插件？

AGW 插件是一个独立的 Sidecar 进程，通过 HTTP 接口与 AGW 主系统通信。它在请求处理链条的关键点介入，实现功能扩展。

## 能做什么？

| 场景 | 示例 |
|------|------|
| 内容过滤 | 拦截/替换不安全 prompt、审查 AI 回复 |
| 格式转换 | 响应前将输出转为特定格式 |
| 自定义路由 | 根据账号属性过滤候选列表 |
| 审计日志 | 异步记录完整请求响应 |
| 代理隧道 | 在 TCP 层建立代理出口（AGP 插件） |

## 不能做什么？

- ❌ 直接访问 AGW 数据库
- ❌ 修改 AGW 核心路由逻辑
- ❌ 创建新的钩子类型
- ✅ 只能通过**已定义的钩子**与 AGW 交互

## 开发流程

```
定义 manifest.json → 实现钩子端点 → 本地测试 → 打包 → 安装
```

## 语言选择

| 语言 | 推荐度 | 原因 |
|------|--------|------|
| Go | ⭐⭐⭐ | 官方 SDK，最小资源占用 |
| Python | ⭐⭐ | 开发快，适合原型 |
| 其他 | ⭐ | 需自行实现 HTTP Server + Token 验证 |

## 插件目录结构

```
my-plugin/
├── manifest.json        # 必需：插件元信息和钩子声明
├── main.go              # 入口文件（Go 示例）
├── Dockerfile           # Docker 部署
└── README.md            # 说明文档
```
