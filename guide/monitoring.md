# 监控与统计

## 管理面板仪表盘

首页仪表盘提供全局概览：

- **今日请求数**：当天总调用量
- **成功率**：200 响应占比
- **平均延迟**：毫秒（ms）
- **Token 用量**：prompt tokens + completion tokens
- **活跃消费者数**：当天有调用的 Key 数量

## 渠道分析

按渠道维度查看：

| 指标 | 说明 |
|------|------|
| 请求分布 | 各渠道接收的请求量 |
| 成功率 | 各渠道的成功/失败比例 |
| 平均延迟 | 各渠道的响应速度 |
| 模型用量 | 每个模型在各渠道的调用量 |

## 账号监控

实时查看每个账号的状态：

| 状态 | 含义 |
|------|------|
| 🟢 active | 正常可用 |
| 🔴 disabled | 已被禁用（故障/限流） |
| 🟡 cooling | 冷却中，等待探测 |

## 消费者分析

- **Top 消费方**：请求量和 Token 用量排行
- **配额使用率**：每个消费者的 RPM/TPM 使用百分比
- **异常检测**：成功率骤降、延迟飙升

## 日志文件

### 请求日志

`logs/agw-YYYY-MM-DD.log`

每次请求一条 JSON 记录，包含完整调用链路（token 用量、状态码、重试链）。

### 每日统计（需开启）

`logs/stats/YYYY-MM-DD.md`

每日生成一份统计摘要。

## 告警

当前版本通过日志监控实现告警。推荐方案：

- 使用 `jq` 实时过滤错误日志
- 对接 external 监控系统（Prometheus + Grafana）
- 插件 `on_log` 钩子实现自定义告警
