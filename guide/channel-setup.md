# 渠道配置

## 创建渠道

管理面板 → 渠道管理 → 添加渠道

### 必填项

| 字段 | 说明 | 示例 |
|------|------|------|
| 名称 | 渠道标识 | "OpenAI-Pro" |
| 适配器 | 协议类型 | openai / anthropic / gemini |
| Base URL | API 端点 | `https://api.openai.com` |

### 可选项

| 字段 | 说明 |
|------|------|
| 权重 | 在分组中的流量占比 |
| Endpoint | 具体路径（默认 `/v1/chat/completions`） |
| 模型重映射 | 替换模型名（如 `gpt-4 → gpt-4-0613`） |
| 模型限制 | 只允许特定模型的数组 |

## 添加账号

渠道创建后 → 点击进入详情 → 账号管理 → 添加账号

| 字段 | 说明 |
|------|------|
| API Key | 上游 API Key（加密存储） |
| 优先级 | 越大越优先（默认 100） |
| 渠道分组 | 所属分组 |

## 渠道分组

```
渠道分组 = 一个流量分发单元

分组 "default":
  渠道A: weight=70
  渠道B: weight=30
→ 70% 请求走渠道A，30% 走渠道B
```

### 为什么需要分组？

- 消费者分组绑定渠道分组 → 控制哪些消费者可用哪些渠道
- 不同渠道分组的流量独立管理

## 模型同步

渠道 → 模型管理 → 自动发现

系统调用上游 `/v1/models` 获取支持的模型列表，审核后激活。

## 常见问题

### 渠道状态显示"不可用"？

1. 检查 API Key 是否正确
2. 检查 Base URL 是否可访问
3. 查看日志中的错误信息

### 账号一直 disabled？

1. 检查 API Key 是否被上游封禁（401）
2. 检查是否触发限流（429）
3. 等待冷却期结束（通常 2 小时）或手动重置
