# 插件管理

## 面板操作

管理面板 → 插件管理提供以下操作：

| 操作 | 说明 |
|------|------|
| 安装插件 | 上传插件包或指定路径 |
| 启用/禁用钩子 | 控制插件的哪些钩子生效 |
| 权限管理 | 授予/撤销插件数据访问权限 |
| 查看日志 | 查看插件运行日志 |
| 卸载插件 | 停用并清理 |

## 安装插件

1. 准备插件包（包含可执行文件 + `manifest.json`）
2. 管理面板 → 插件管理 → 安装
3. 选择插件目录或上传压缩包
4. 系统验证 `manifest.json`
5. 安装完成 → 需手动启用

## 权限管理

插件安装后，进入权限标签页：

- 查看插件声明的权限列表
- 逐项勾选授予的权限
- 🔴 高敏感权限需二次确认
- 即时生效，无需重启

## 插件健康

运行中插件实时状态：

| 状态 | 含义 |
|------|------|
| 🟢 正常 | 插件运行中，健康检查通过 |
| 🟡 重启中 | 上次崩溃后正在恢复 |
| 🔴 已停用 | 崩溃次数超限，需手动干预 |

## 查看日志

插件 stdout 输出由 AGW 收集，可在面板查看：

- 实时日志流
- 错误高亮
- 按时间过滤

## 禁用/卸载

- **禁用**：保留插件和配置，停止钩子调用
- **卸载**：完全删除插件及其数据

建议先禁用确认不影响业务，再彻底卸载。
