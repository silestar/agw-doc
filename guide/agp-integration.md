# AGP 代理池集成

## AGP 是什么？

AGP（AGW Edge Proxy）是一个独立的代理节点管理系统。它配合 AGW 的 `connection_decorator` 钩子，为每个账号分配独立的代理出口。

## 为什么需要代理池？

| 场景 | 收益 |
|------|------|
| 多账号同 IP | 避免被上游识别和限制 |
| 地域路由 | 选择离上游最近的节点 |
| 账号隔离 | 不同账号走不同 IP |
| 高可用 | 节点故障自动切换 |

## 部署架构

```
┌──────┐    ┌──────────┐    ┌──────────────┐    ┌──────────┐
│ 用户  │───→│   AGW    │───→│  AGP Proxy   │───→│ mihomo   │
│      │    │          │    │  Plugin       │    │ 节点     │
└──────┘    └──────────┘    └──────────────┘    └──────────┘
                                    │
                              ┌─────┴─────┐
                              │  mihomo   │
                              │  Controller│
                              └───────────┘
```

## 安装步骤

1. 部署 AGP 服务
2. 添加代理节点
3. 在 AGW 安装 AGP Proxy 插件
4. 启用 `connection_decorator` 钩子
5. 在渠道设置中关联代理策略

## 节点选择

AGP 负责选择出口节点，mihomo 仅作执行：

```
AGP 决策 → PUT /proxies/{group} 切节点 → 隧道就绪 → AGW 建 TLS
```

## 粘性绑定

同一账号的请求优先走同一节点：
- StickyKey 由 `account_id` 生成
- TTL 内复用同一节点
- 节点不可用时自动重新分配
