# 状态码说明

## HTTP 状态码

| 状态码 | 含义 | 可能原因 |
|--------|------|---------|
| 200 | 成功 | — |
| 400 | 请求格式错误 | JSON 格式不正确、缺少必填字段 |
| 401 | 认证失败 | Consumer Key 无效或已吊销 |
| 403 | 权限不足 | 消费者无权限访问该模型 |
| 404 | 模型未找到 | 请求的模型在可用渠道中不存在 |
| 429 | 限流 | 消费者配额耗尽、或上游账号被限流 |
| 499 | 客户端断开 | 客户端在响应完成前关闭连接 |
| 500 | 内部错误 | 所有候选渠道均失败（详见日志） |
| 502 | 上游错误 | 上游返回非预期响应 |
| 503 | 服务不可用 | 无可用渠道或账号 |

## 499 的特殊处理

| 场景 | 是否计入故障 |
|------|-------------|
| 已发送数据后客户端断开 | ❌ 不计 |
| 未发送数据即断开 | ✅ 计入，触发故障降级 |
| context.Canceled | ❌ 不计（客户端主动取消） |

## 错误响应格式

AGW 在非 200 时返回 OpenAI 格式错误：

```json
{
  "error": {
    "message": "No available channels found for model: gpt-4",
    "type": "no_available_channel",
    "code": "404"
  }
}
```

## 常见问题

### 突然所有请求返回 500？

1. 检查所有渠道是否不可用（管理面板 → 渠道列表）
2. 检查上游服务状态
3. 查看日志中的具体错误信息

### 消费者收到 429 但不是上游限流？

1. 检查消费者 RPM/TPM 配额
2. 查看消费者分组配额设置
3. 调整配额或等待配额窗口重置
