# 什么是 AGW？

AGW（AIGateway）是一个放在你的应用和 AI 服务商之间的**智能中间层**。你像调用 OpenAI 一样调用 AGW，AGW 帮你：

- 🎯 **智能选择**：自动挑选最合适的渠道和账号
- 🔄 **故障转移**：一个账号挂了，自动换下一个
- 📊 **用量统计**：谁用了多少 Token，钱花在哪
- 🔑 **多租户**：生成多个 Key 分给不同用户，各自独立配额

## 一句话理解

```
你的应用 → AGW → 渠道A (OpenAI Key1, Key2)
              → 渠道B (Anthropic Key1)
              → 渠道C (Gemini Key1, Key2, Key3)
```

AGW 是那个帮你管理所有 API Key 的中间人。

## 核心概念

| 概念 | 通俗理解 |
|------|---------|
| **渠道** | 一个上游服务商（如 OpenAI）的一条接入路径 |
| **账号** | 一个上游 API Key（一个渠道可以有多个账号） |
| **消费者** | 你发给用户的 API Key（一个消费者 = 一个调用方） |
| **分组** | 一组渠道或一组消费者的集合，用于批量管理 |
| **配额** | 每分钟最大请求数（RPM）和 Token 数（TPM） |

## 适用场景

- **内部工具**：多个团队共用一套 AI 服务，独立配额和统计
- **SaaS 产品**：给你的客户分配 Key，控制用量
- **个人开发**：多个 API Key 轮流用，避免限流
- **代理服务**：整合多个 AI 服务商，提供统一接口
